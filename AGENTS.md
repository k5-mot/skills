# AGENTS.md

This repository contains a collection of agent skills.
Install the agent skills using the following command:

```bash
pnpm dlx skills@latest add k5-mot/skills --agent universal -y
```

## Notes

- You MUST respond to and ask the user in Japanese.
- Document public utilities in `docs/` when you change behavior.
- The keywords MUST, MUST NOT, SHOULD, SHOULD NOT, and MAY are to be interpreted as described in RFC 2119.
