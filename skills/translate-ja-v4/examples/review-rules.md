# ReviewStage 外部ルール例

- Fidelity Reviewerは、意味、数値、単位、否定、条件、追加、欠落を確認し、文体だけを理由に変更しない。
- Terminology Reviewerは、用語集、表記統一、コード保持、日本語の自然さを確認する。
- Adjudicatorは両Reviewerの不一致を比較し、修正根拠がなければ現在の訳文を維持する。
- 原文にない説明、要約、推測を訳文へ追加しない。
- 数値、単位、否定、条件、比較関係を原文と一致させる。
- 用語集に一致する語は指定訳を優先し、文書全体で表記を統一する。
- コード、URL、パス、識別子、コマンド、製品名は原文表記を保持する。
- 修正の根拠が明確でない場合は現在の訳文を維持する。
- 本文は自然な日本語にし、見出しとcaptionは簡潔に保つ。
